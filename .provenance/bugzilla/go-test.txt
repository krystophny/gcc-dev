The imported go.test subtree under gcc/gcc/testsuite/go.test contains a large
number of files with explicit third-party provenance headers, for example:

- gcc/gcc/testsuite/go.test/test/alias2.go
- gcc/gcc/testsuite/go.test/test/run.go

These files state that the code is governed by a BSD-style license found in a
LICENSE file, but there is no colocated LICENSE under
gcc/gcc/testsuite/go.test.

Equivalent Go license texts exist elsewhere in the GCC tree:

- gcc/libgo/LICENSE
- gcc/gcc/go/gofrontend/LICENSE

That means the import is not wholly unattributed, but the imported subtree
itself does not carry the local license companion that its file headers point
to.

Suggested patch direction:

1. Add a colocated LICENSE file for gcc/gcc/testsuite/go.test that matches the
   imported Go tests' BSD license terms.
2. Optionally add a short top-level note in that subtree explaining that the
   files are imported from the Go project testsuite.
3. If some files come from different upstream snapshots, preserve that
   provenance in comments or a subtree note.

This was identified during a whole-tree provenance audit on 2026-04-18.
