Title: Lost typespec with constant expressions using array constructors and parentheses
Status: RESOLVED FIXED
Resolution: Commit c50d263beff (r16-5803), committed 2025-12-01 by Harald Anlauf
Priority: P3 normal
Component: fortran
Reported by: anlauf@gcc.gnu.org (2022-11-16)
Keywords: wrong-code
Duplicates: 107820

Summary:
  Array constructors that use an explicit type-spec lose that type when the
  constructor expression is wrapped in parentheses. Constant-folded expressions
  therefore re-evaluate elements using their original literal types instead of
  the declared type, which produces wrong runtime results for INTEGER/REAL/
  COMPLEX conversions. GCC 10 used to ICE, GCC 11+ produces wrong answers.

Fix:
  Added conversion logic in arith.cc and improved expression simplification
  and nested constructor handling in array.cc. New test added in
  gfortran.dg/array_constructor_typespec_1.f90.
